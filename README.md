# Ciencia de Datos - Prácticas y Proyectos

Repositorio que recopila las prácticas de laboratorio, ejercicios prácticos y notas desarrolladas a lo largo de la materia de Ciencia de Datos. Incluye desde la introducción al análisis exploratorio y extracción de información web, hasta modelos clásicos de aprendizaje automático y redes neuronales.

---

## 📁 Estructura del Repositorio

El contenido está organizado por temas y prácticas progresivas:

```text
├── 07_ redes neuronales/              # Implementación y arquitectura de redes neuronales profundas
├── Redes neuronales/                  # Conceptos fundamentales y primeros modelos neuronales
├── kmeans/                            # Modelos de clustering no supervisado (K-Means)
├── Naive bayes/                       # Clasificación probabilística mediante Naive Bayes
├── webscrapping/                      # Extracción automatizada de datos web y exportación (BeautifulSoup/Pandas)
├── Tratamiento de complejidad de datos/ # Limpieza, normalización y reducción de dimensionalidad
├── Clase 3-4 EDA/                     # Análisis Exploratorio de Datos (EDA) y visualización estadística
├── EDA libros/                        # Proyecto/caso práctico de EDA aplicado a dataset de libros
└── primeros pasos/                    # Cuadernos introductorios de sintaxis y librerías base
